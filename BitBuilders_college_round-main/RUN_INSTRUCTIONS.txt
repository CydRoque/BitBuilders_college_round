================================================================================
FAIRWORK - RUN & SETUP INSTRUCTIONS
================================================================================

1. PREREQUISITES
--------------------------------------------------------------------------------
- Python 3.9+ installed and added to PATH.

2. OPEN TERMINAL / COMMAND PROMPT
--------------------------------------------------------------------------------
Open PowerShell or Command Prompt (cmd) and navigate to the project directory:

cd D:\Rylan\code\bnB\BitBuilders_college_round-main

3. INSTALL DEPENDENCIES (ONE-TIME SETUP)
--------------------------------------------------------------------------------
Run the following command to ensure all required packages are installed:

pip install flask flask-socketio eventlet

4. RUN THE SERVER
--------------------------------------------------------------------------------
Execute the application as a Python module from the project root:

python -m backend.app

5. ACCESS THE APPLICATION
--------------------------------------------------------------------------------
Open your web browser and navigate to:

- Main Platform Demo:   http://127.0.0.1:5000/
- Authentication Page:  http://127.0.0.1:5000/login

6. HOW TO STOP THE SERVER
--------------------------------------------------------------------------------
In the terminal window where the server is active, press:

Ctrl + C
